Valora MCP server

Valora's public MCP (Model Context Protocol) server gives AI applications read-only access to our educational financial-planning content: guides for tech employees, physicians and business owners, insights articles, and the documentation for 30 financial calculators. Content is educational only - Valora does not provide investment advice and is not arranging advisor matches or introductions at this time.

Endpoint

https://api.valorahq.com/mcp

MCP Streamable HTTP transport. POST JSON-RPC requests to this URL. Stateless - no authentication and no session required. A health check is available at GET /mcp/health.

Tools

All tools are read-only and free to call.

search_content

Full-text search across the indexed public content library. Returns ranked matches with URL, description and excerpt.

  • query (string, required) - search terms, e.g. "roth conversion tax"
  • limit (integer, optional, 1-20, default 5) - maximum results

list_pages

List indexed pages with URLs and one-line descriptions.

  • section (string, optional) - one of guides, calculators, insights, legal

get_page

Get the full text content of a page by URL, using a URL from list_pages or search_content.

  • url (string, required) - full page URL on www.valorahq.com

Example calls

Initialize the MCP connection:

curl -X POST https://api.valorahq.com/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize",
       "params":{"protocolVersion":"2025-03-26","capabilities":{},
       "clientInfo":{"name":"my-client","version":"0.1"}}}'

Search the content library:

curl -X POST https://api.valorahq.com/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call",
       "params":{"name":"search_content",
       "arguments":{"query":"401k contribution limit","limit":3}}}'

Connect from an MCP client

Claude (claude.ai): go to Customize > Connectors > Add custom connector, then paste https://api.valorahq.com/mcp. No authentication is needed. On Claude Team and Enterprise plans, a workspace owner adds the connector for the organization first. Setup guide: Anthropic - get started with custom connectors using remote MCP.

ChatGPT: enable developer mode, then create an app with the MCP server URL set to https://api.valorahq.com/mcp. Requires a supported ChatGPT account; workspace permissions may apply. Guides: OpenAI - developer mode and OpenAI help - connectors and MCP.

Other MCP clients: use your client's remote MCP/Streamable HTTP configuration instructions with the endpoint above.

Content and refresh cadence

The server mirrors the published valorahq.com content library (the same corpus the site exposes as llms.txt and llms-full.txt): educational guides for tech employees, physicians and business owners, insights articles, the documentation for 30 financial calculators, and the site's core and legal pages. The current indexed-page count is available at GET /mcp/health.

Content refreshes automatically: a scheduled job on the server syncs the library from the current published site build every 15 minutes, and the server reloads changed content in place. New guides, articles and calculators appear in the MCP tools after the next successful sync.

Notes

  • All tools are read-only. The server is stateless: no accounts, no sessions, no cookies and no database. It returns only content already published on valorahq.com.
  • Do not include private client information, credentials or account details in requests.
  • Logging: the server keeps no request log. Its container log holds only startup and content-reload lines, and no access log is configured on the proxy in front of it.
  • Content is educational information about financial planning, not investment advice.
  • See our privacy policy and terms. Questions about the content: send us a request.
